## 9.1. Vai trò của Unit Test

> **Unit Test** là kiểm thử ở mức độ nhỏ nhất (thường là 1 hàm hoặc 1 class) một cách độc lập hoàn toàn với các hệ thống bên ngoài (như DB, API thứ ba).
> **Lợi ích**: 
> 1. Phát hiện bug sớm ngay khi vừa viết xong code. 
> 2. Giúp refactor (sửa cấu trúc code) tự tin hơn vì lỡ làm hỏng logic cũ thì test sẽ lập tức báo đỏ (Fail). Mệnh danh là "tấm khiên bảo vệ source code".

## 9.2. JUnit

> **JUnit** là framework tiêu chuẩn để viết và chạy test trong hệ sinh thái Java. Cung cấp các annotation như `@Test`, `@BeforeEach` (chạy trước mỗi test để setup data), `@AfterEach`. Dùng `Assertions` để đối chiếu kết quả (Expected vs Actual).

```java
class CalculatorTest {
    @Test
    void testAdd() {
        Calculator calc = new Calculator();
        int result = calc.add(2, 3);
        
        // So sánh: Mong đợi bằng 5, kết quả thực tế, thông báo nếu sai
        assertEquals(5, result, "2 + 3 phải bằng 5");
    }
}
```

## 9.3. Mockito

> **Mockito** là thư viện dùng để tạo ra các "vật thế thân" (Mock object). Khi test Service, ta không muốn gọi thật xuống Database (vì chạy chậm, rủi ro làm bẩn DB thật), ta sẽ "mock" thằng Repository để nó trả về data giả ngay lập tức.

```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    
    @Mock // Làm giả thằng đệ (Repository)
    UserRepository userRepository; 
    
    @InjectMocks // Thằng Service cần test thật, nhét thằng giả vào bụng nó
    UserService userService; 
    
    @Test
    void testFindUser() {
        // Kịch bản (Stubbing): Hễ code gọi findById(1) thì bắt nó lập tức trả về tên "Ramen"
        User fakeUser = new User("Ramen");
        when(userRepository.findById(1L)).thenReturn(Optional.of(fakeUser));
        
        // Chạy thử hàm service, sẽ KHÔNG chạm tới DB thật
        User result = userService.getUserById(1L);
        assertEquals("Ramen", result.getName());
    }
}
```

## 9.4. MockMvc

> Dùng trong Spring Boot để test riêng tầng **Controller** (Web Layer) mà không cần phải bật hẳn web server (như Tomcat) tốn thời gian. Nó mô phỏng lại một HTTP Request (gửi POST, GET, kèm JSON Body) và kiểm tra HTTP Status code/nội dung JSON trả về.

```java
@WebMvcTest(UserController.class)
class UserControllerTest {

    @Autowired
    MockMvc mockMvc; // Công cụ giả lập trình duyệt gọi API cực nhanh

    @Test
    void testGetUser() throws Exception {
        mockMvc.perform(get("/api/users/1")) // Giả lập lời gọi GET tới API
               .andExpect(status().isOk())   // Kỳ vọng HTTP Status Code trả về 200 OK
               .andExpect(jsonPath("$.name").value("Ramen")); // Kỳ vọng cục JSON trả về có chữ "Ramen"
    }
}
```
