## 7.1. Git

> **Git** là hệ thống quản lý phiên bản phân tán (VCS). Giúp team cùng làm việc chung trên một mã nguồn mà không giẫm chân lên nhau.
> **Các lệnh hay dùng**: `git clone`, `git pull`, `git add`, `git commit`, `git push`. Phân biệt `merge` (có commit rẽ nhánh) và `rebase` (thẳng tuyến tính).

```bash
# Sửa lỗi lỡ commit nhầm (xóa commit cuối, giữ lại code trên máy để sửa tiếp)
git reset --soft HEAD~1
```

## 7.2. Docker

> **Docker** là nền tảng ảo hóa cấp hệ điều hành (Containerization).
> **Lợi ích**: Đóng gói toàn bộ code, môi trường, thư viện vào 1 file (Image). Chạy Image đó trên mọi máy (Container) đều ra kết quả giống hệt nhau, giải quyết dứt điểm câu nói *"Code chạy ngon trên máy em, mà lên server lại lỗi"*.

```dockerfile
# Dockerfile chạy Spring Boot siêu đơn giản
FROM openjdk:17-jdk-slim
COPY target/app.jar app.jar
ENTRYPOINT ["java", "-jar", "/app.jar"]
```

## 7.3. Redis

> **Redis** là hệ quản trị CSDL in-memory (lưu trên RAM), dạng Key-Value.
> **Lợi ích**: Tốc độ đọc/ghi cực kỳ khủng khiếp (micro giây). Thường dùng làm **Cache** (lưu dữ liệu hay truy cập để giảm tải cho Database chính), quản lý **Session** phân tán, hoặc đếm view/rate limiter.

```java
// Spring Boot tích hợp Redis siêu dễ với Spring Cache
@Cacheable(value = "categories")
public List<Category> getCategories() {
    // Hàm này chạy lần đầu sẽ query DB. Lần 2 sẽ tự động móc từ RAM Redis ra, nhanh gấp 100 lần.
    return repository.findAll();
}
```

## 7.4. Kafka / RabbitMQ

> **Message Queue (Kafka, RabbitMQ)** là hệ thống gửi/nhận tin nhắn bất đồng bộ (Asynchronous) giữa các services. Hoạt động theo mô hình Publisher (người đẩy) - Consumer (người hút).
> **Lợi ích**: 
> 1. **Chống nghẽn cổ chai**: Hệ thống đang bị nghẽn (VD flash sale), đẩy request vào hàng đợi để xử lý từ từ, tránh sập server (Peak Load Leveling).
> 2. **Giảm kết dính (Decoupling)**: Service Mua hàng chỉ cần ném sự kiện "Đã mua" vào Kafka, Service Gửi Email tự lấy ra gửi. Service Mua hàng không cần chờ Service Email chạy xong mới báo thành công cho user.

## 7.5. Linux cơ bản

> Dev Backend thường xuyên phải thao tác với server Linux để deploy và debug. 
> Các lệnh quan trọng nhất cần nhớ đi phỏng vấn:
> - Xem log real-time: `tail -f application.log`
> - Tìm chữ lỗi Exception trong file: `grep -i "NullPointer" error.log`
> - Xem port nào đang chạy (xem app có bị chết không): `netstat -tulpn | grep 8080`
> - Xem RAM có bị tràn không: `free -m` hoặc dùng `top` / `htop`
